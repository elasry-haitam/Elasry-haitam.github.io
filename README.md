# Haitam Elasry : Personal Website and Systems Portfolio

A minimalist, high-performance personal portfolio and systems architecture case study website.
Built with pure HTML5, CSS3, and vanilla JavaScript. Zero frameworks, zero build steps, zero external dependencies.

---

## Architecture and Structure

- **`index.html`**: Main landing page (Overview, Selected Work, Career Timeline, Academic Background, Technical Capabilities).
- **`sales-companion.html`**: Technical Systems Architecture whitepaper for **Sales Companion (Allianz Partners)**.
- **`sports-insights.html`**: Applied Machine Learning and Statistical Modeling case study for **Sports Insights (PCA, ANOVA)**.
- **`style.css`**: Shared styling blending Karpathy-style minimalism with Distill editorial clarity, featuring a dynamic dark/light theme toggle persisted in `localStorage`.

---

## Design Principles

- **Zero Framework Overhead:** Instant load times with pure native browser technologies.
- **Strict Privacy and Governance:** Public codebase contains zero proprietary datasets, zero enterprise credentials, and zero personal contact identifiers.
- **Responsive and Accessible:** Designed for optimal readability across desktop and mobile screens.

---

## Local Development

Simply open `index.html` in any modern web browser, or serve locally with Python:

```bash
python -m http.server 8000
```

Navigate to `http://localhost:8000`.
